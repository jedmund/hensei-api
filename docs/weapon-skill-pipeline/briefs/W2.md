# W2: migration-only state → curation

**Wave 1.** Depends on W0. Migration block `…11xxxx` (you shouldn't need one). Branch `pipeline/W2-<a|b>`. Issue label `pipeline:W2`.

## Goal

Make today's data reproducible from sources plus curation. Every value that exists only because a migration wrote it becomes a committed curation entry, or is filed as a parser fix.

## Input

`bin/rails granblue:skill_parity mode=full_reparse group=series` on your pipeline database. On 2026-10-15 this showed 103 versions on 81 weapons:

| Difference | Versions |
|---|---|
| Skill size dropped (31 Excelsior, 7 Crux) | 38 |
| Family link dropped (Might, Grace, Roar, Charge, Blow, Healing) | ~20 |
| Unlock gates reset (Grand Epic, Heroic Tale, Absolute Equality, Staff Resonance, Exo 5★ skills) | 9 |
| Fifth-slot Majesty skills deleted (10 weapons) | 10 |
| Rows lost or changed (Forest Blessing, Bountiful Strike, Architect Battle Arts, Magic Charge, Excess Voltage, Drago Surge, Scales of Wrath, Wicked Might ×3) | 11 |
| New tiers now on the wiki (Nue II, Thunder God III, Purity of Nature III…) | 26 |

## Classify every difference into exactly one bucket

- **`curate`:** today's value is right but isn't produced by the parser. Write the overlay entry:
  - v1 now: size, family or series override, curated row, suppression;
  - v2 structural ops (`gate`, `add_version`) as fragments under `data/weapon_skill_curation/pending/<series>.json` in the overlay v2 format. W7's applier picks them up.
- **`parser`:** the parser should produce today's value; it's a parser bug. Write it up for W6 with the weapon, the skill, the source text and the expected output.
- **`accept`:** the new value is right (for example, a tier that's now on the wiki). Cite the gbf.wiki page and section. The user reviews these in the PR.

Record every difference in `docs/weapon-skill-pipeline/w2-classification.md`, one row each: key, bucket, evidence, entry or issue.

## Split (if two agents)

- **W2a:** Excelsior, Crux and the family links.
- **W2b:** gates, Majesty slots, rows and new tiers.

Each agent edits curation only for the series in its rows.

## Owned files

- the curation files for the affected series
- `data/weapon_skill_curation/pending/**`
- `docs/weapon-skill-pipeline/w2-classification.md`

**Forbidden:** all code. Parser problems become `parser` rows.

## Acceptance

- Every one of the 103 differences is classified.
- Once W7 lands, `mode=full_reparse` shows only `parser` and `accept` rows.
- The drift check is clean.
